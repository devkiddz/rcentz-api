# Rcentz Brand Identity

## Official typeface

RcentzBrand Regular is the official Rcentz brand typeface.

Font files:
- `/brands/rcentz/RcentzBrand-Regular.ttf`
- `/brands/rcentz/RcentzBrand-Regular.woff`

Geist Sans is reserved for application and interface typography.

## Official logo assets

- `rcentz-cr-lockup-light.svg`
- `rcentz-cr-lockup-dark.svg`
- `rcentz-cr-symbol-blue.svg`

## Official colours

| Role | Colour |
|---|---|
| Primary blue | #4260E6 |
| Light wordmark | #0D0D0D |
| Dark wordmark | #FAFAFA |

## Usage

- Use the complete CR lockup as the primary logo.
- Select the light or dark variant according to the background.
- Use the standalone symbol for compact brand placements.
- Preserve the original logo proportions.
- Do not distort, rearrange or independently recreate the identity.

## API manifest

GET /api/v1/brand

The manifest provides the official logo, symbol, font, colour and usage
references for applications consuming the Rcentz brand identity.

Static assets are served from `/brands/rcentz/`.
Asset paths are relative to the API origin.
